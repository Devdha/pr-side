# PR Side Chrome Web Store Listing

## English listing

### Name

PR Side – GitHub PR Tabs

### Summary

Unofficial helper that organizes your GitHub pull requests into Chrome tab groups.

### Detailed description

PR Side keeps pull requests beside your work without turning your tab bar into a backlog.

It automatically organizes pull requests you authored and pull requests awaiting your review into Chrome tab groups. You can use one combined group or separate “My PRs” and “Review requests” groups, choose a synchronization interval, and limit results by recent activity.

PR Side is an unofficial, independent extension and is not affiliated with or endorsed by GitHub. Pull-request data is processed locally in your browser and is not sent to an external server.

### Single purpose

Organize the signed-in user's GitHub pull requests into Chrome tab groups.

### Host permission justification

Access to `https://github.com/*` is required to read the signed-in user's authored and review-requested pull-request list pages and open those pull requests as grouped tabs. The extension processes this data locally and does not transmit it outside the browser.

### Permission justifications

- `tabs`: open and maintain tabs for the detected pull requests.
- `tabGroups`: create and update the “My PRs” and “Review requests” groups.
- `storage`: save user settings, synchronization state, and tab-group identifiers.
- `alarms`: synchronize at the interval selected by the user.

### Privacy disclosures

- Data collection: none.
- Data sale or sharing: none.
- External analytics or advertising: none.
- Website content access: GitHub pull-request list content is read and processed locally for the extension's single purpose.
- Limited Use: declare compliance in the Chrome Web Store Privacy tab.

## 한국어 등록 정보

### 이름

PR Side – GitHub PR Tabs

### 요약

GitHub PR을 Chrome 탭 그룹으로 정리하는 비공식 도우미입니다.

### 상세 설명

PR Side는 내가 작성한 PR과 리뷰 요청을 받은 PR을 Chrome 탭 그룹으로 자동 정리합니다.

모든 PR을 하나의 그룹으로 모으거나 “내 PR”과 “리뷰 요청”으로 나눌 수 있습니다. 동기화 주기와 최근 활동 기간도 설정할 수 있습니다.

PR Side는 GitHub와 제휴하거나 GitHub의 승인을 받은 공식 제품이 아닙니다. PR 정보는 사용자의 브라우저 안에서만 처리되며 외부 서버로 전송되지 않습니다.
