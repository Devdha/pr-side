# PR Side

한국어 | [English](./README.md)

GitHub Pull Request를 크롬 탭 그룹으로 자동 정리해주는 비공식 크롬
익스텐션입니다 - 내가 올린 PR과 내가 리뷰어로 지정된 PR을 Arc 브라우저의
고정 폴더처럼 관리합니다.

## 주요 기능

- **자동 동기화** - "내 PR"과 "리뷰 요청" 두 개의 탭 그룹을 주기적으로,
  그리고 팝업의 "지금 동기화" 버튼으로 최신 상태로 유지합니다.
- **자동 정리** - 머지되거나 닫힌 PR의 탭을 자동으로 닫습니다.
- **활동 기간 필터** - 최근 N일 이내에 활동이 있었던 PR만 표시합니다
  (설정 가능, 0 = 전체 표시).
- **메모리 절약** - 새 탭은 로드가 끝난 뒤 메모리에서 내려가며, 제목과
  파비콘은 유지됩니다. PR이 많아도 브라우저가 무거워지지 않습니다.
- **형식 변경 안전장치** - GitHub 페이지 구조가 바뀌어 파서가 갑자기 PR을
  0개로 인식하면, 이를 그대로 믿지 않고 의심 상태로 전환합니다. 기존 탭을
  보존한 채 여러 번의 동기화에서 같은 결과가 확인될 때만 반영합니다.
- **재시작 대응** - 크롬 재시작 시 탭 그룹 ID가 바뀌어도 제목으로 복원된
  그룹을 찾아 이어받고, 실수로 생긴 중복 그룹은 자동으로 병합합니다.
- **Draft PR 필터** - 원하면 draft 상태인 PR을 두 그룹 모두에서 제외할 수
  있습니다.
- **툴바 배지** - 아직 처리하지 않은 리뷰 요청 개수를 한눈에 보여줍니다.
- **리뷰한 PR 유지** - 리뷰를 남긴 순간 목록에서 사라지지 않고, 실제로
  머지되거나 닫힐 때까지 "리뷰 요청" 그룹에 계속 표시됩니다.
- **최근 활동순 정렬** - 그룹 내 탭이 최근 활동 순으로 정렬되며, 설정을
  저장하면 다음 주기를 기다리지 않고 바로 다시 동기화됩니다.
- **다국어 지원** - 브라우저 언어에 따라 한국어/영어 UI를 제공합니다.

## 동작 방식

PR Side는 브라우저에 이미 로그인된 `github.com` 세션을 이용해 `/pulls`
대시보드 페이지를 읽고, 내가 올린 PR과 리뷰 요청받은 PR을 찾습니다.
OAuth 앱도, API 토큰도, 외부 서버도 없습니다 - 모든 파싱과 탭 관리는
브라우저 안에서만 이루어지며, 데이터는 GitHub 외의 어디로도 전송되지
않습니다.

안정적인 공개 API 대신 GitHub 페이지의 HTML과 내장 데이터를 파싱하는
방식이므로, GitHub이 페이지 구조를 바꾸면 동작이 깨질 수 있습니다. 그런
경우에도 기존 탭을 그대로 보존하고 팝업에 경고를 표시하도록 설계되어
있습니다.

## 설치

**Chrome Web Store:** _(준비 중)_

**직접 설치 (unpacked):**

```bash
npm install
npm run build
```

이후 크롬에서 `chrome://extensions`로 이동해 "개발자 모드"를 켜고,
"압축해제된 확장 프로그램을 로드"로 생성된 `dist/` 디렉터리를 선택하세요.

## 개발

```bash
npm run build       # esbuild로 dist/에 번들
npm test            # vitest 테스트 실행
npm run typecheck   # tsc --noEmit
```

프로젝트 구조:

- `src/lib/parser.ts` - GitHub HTML과 내장 JSON에서 PR 데이터를 추출하는
  순수 함수 (Chrome API 미사용, 단위 테스트 대상).
- `src/lib/github.ts` - 브라우저 세션 쿠키로 `/pulls` 페이지를 가져오는
  데이터 소스 어댑터.
- `src/lib/filter.ts` - 활동 기간 필터.
- `src/lib/sync.ts` - 탭 그룹 동기화 엔진: 대상 PR과 기존 탭의 diff,
  재시작 후 그룹 입양/병합, 형식 변경 안전장치, 제목을 유지하는 탭 언로드.
- `src/background.ts` - 알람과 메시지를 동기화 엔진에 연결하는 MV3 서비스
  워커.
- `src/popup/`, `src/options/` - 팝업 UI와 설정 페이지.
